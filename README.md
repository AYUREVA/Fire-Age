# Fire Age

Браузерная игра для курса **«Проектирование и разработка игровых приложений»**.

Стек: **TypeScript + Phaser 4 + Vite + GitHub Pages**.

Ледниковый период, вид сверху под углом. Ты — вождь маленького племени пещерных людей: рубишь заснеженные кусты хвороста, носишь связки стопкой за спиной и складываешь их в поленницу у костра. Огонь нужно держать живым всю ночь, до рассвета.

Сейчас это **версия 0.2 — живой костёр и пауза**: у игры есть цель (дожить до рассвета), риск (огонь гаснет), поражение, рестарт и пауза. Смена дня и ночи, охота, готовка, враги и эпохи появятся в следующих версиях.

### Как играть

- Подойди к кусту — вождь сам замахивается и бьёт его дубиной, а связки хвороста прилетают на стопку за спиной.
- Кусты присыпаны снегом: первый удар стряхивает снег, дальше куст зелёный и с каждым ударом редеет.
- Хворост в кусте кончился — остаётся пенёк, через несколько секунд куст отрастает снова заснеженным.
- Стопка не бесконечная: когда над головой «МАКС», неси хворост к костру.
- Встань на площадку поленницы — связки по одной улетают в кучу. В поленнице помещается 12 связок.
- Костёр всё время горит, и жар убывает — это шкала над огнём. Когда жара мало, связка из поленницы сама летит в огонь. Чем меньше жара, тем меньше пламя и свет.
- Жар упал до нуля — остаются угли, шкала мигает. Есть 10 секунд, чтобы принести хворост: огонь разгорится снова. Не успел — «КОСТЁР ПОГАС».
- В левом верхнем углу — сколько осталось до рассвета. Дожил с живым огнём — «РАССВЕТ!».
- После итога — «Заново», пробел, Enter или клик: игра начинается с нуля.

### Управление

| Действие | Клавиатура | Мышь / тач |
|---|---|---|
| Идти | WASD или стрелки | зажми и веди: где нажал — там центр джойстика |
| Рубить куст | встать рядом | встать рядом |
| Сдать хворост | встать на площадку поленницы | встать на площадку поленницы |
| Пауза | P или Esc | кнопка в правом верхнем углу |

Игра сама встаёт на паузу, если свернуть вкладку.

### Настройки игры

Все игровые числа — в [`src/game/settings.ts`](./src/game/settings.ts). Поменяй число, сохрани файл — игра перезапустится сама. Сильнее всего на ощущения влияют:

| Константа | Сейчас | Что меняет |
|---|---|---|
| `PLAYER_SPEED` | 260 | скорость вождя (пикселей в секунду) — темп всей игры |
| `STACK_CAPACITY` | 10 | сколько связок помещается в стопку, как часто бегать к костру |
| `HIT_INTERVAL` | 450 | пауза между ударами по кусту (мс) — скорость добычи; взмах дубиной подстраивается сам |
| `DROP_INTERVAL` | 110 | пауза между связками при сдаче (мс) |
| `BUSH_STOCK` | 4 | сколько связок в одном кусте |
| `BUSH_REGROW_TIME` | 8000 | через сколько мс пенёк снова становится кустом |
| `GATHER_RADIUS` / `DROP_RADIUS` | 140 / 95 | как близко подойти к кусту / поленнице |
| `NIGHT_DURATION` | 120000 | сколько длится ночь до рассвета (мс) |
| `FIRE_BURN_TIME` | 20000 | за сколько мс полный костёр прогорает до нуля |
| `HEAT_PER_BUNDLE` | 25 | сколько % жара даёт одна связка |
| `FIRE_FEED_BELOW` | 75 | ниже этого жара (%) связка из поленницы сама летит в огонь |
| `EMBER_TIME` | 10000 | сколько мс тлеют угли, пока огонь можно спасти |
| `WOODPILE_CAPACITY` | 12 | сколько связок помещается в поленницу |

## 1. Что нужно установить

- **Node.js 22 LTS** (или Node.js >= 20.19)
- **Git**
- **VS Code** или другая IDE
- аккаунт **GitHub**

Проверка:

```bash
node --version
npm --version
git --version
```

## 2. Первый запуск

```bash
npm install
npm run dev
```

Vite напечатает адрес локального сервера. Обычно это:

```text
http://localhost:5173/
```

Открой его в браузере.

## 3. Проверка production build

Перед публикацией:

```bash
npm run build
```

Если команда завершилась без ошибок, итоговая версия находится в папке `dist/`.

Её можно проверить локально:

```bash
npm run preview
```

## 4. Публикация на GitHub Pages

В репозитории уже есть workflow:

```text
.github/workflows/deploy.yml
```

После push в ветку `main` GitHub автоматически собирает проект.

Для первого включения Pages:

1. открой репозиторий на GitHub;
2. **Settings → Pages**;
3. в **Build and deployment → Source** выбери **GitHub Actions**;
4. открой вкладку **Actions** и дождись успешного `Deploy to GitHub Pages`;
5. ссылка на игру появится в deployment и в разделе Pages.

## 5. Архитектура

```text
public/
└── fonts/                     # шрифт Russo One для табличек и таймера + его лицензия OFL.txt
src/
├── main.ts                    # точка входа: подключает стили и запускает игру
├── style.css                  # оформление страницы вокруг canvas
└── game/
    ├── config.ts              # настройки Phaser: размер 960×640, масштаб, список сцен, честное время с первого кадра
    ├── settings.ts            # все игровые параметры для гейм-дизайнера: ночь, мир, вождь, стопка, кусты, костёр, поленница
    ├── palette.ts             # все цвета игры
    ├── textures.ts            # рисует все картинки кодом при старте; ключи TEXTURES, шрифты и их загрузка
    ├── fx.ts                  # эффекты-функции: полёт по дуге, «+1», встряска, «пружинка»
    ├── scenes/
    │   ├── GameScene.ts       # игра: строит мир, создаёт объекты, в update() по очереди зовёт системы
    │   ├── PauseScene.ts      # пауза поверх игры: «Продолжить» и «Заново»
    │   └── ResultScene.ts     # итог ночи поверх игры: «РАССВЕТ!» или «КОСТЁР ПОГАС», рестарт
    ├── systems/               # правила игры — функции, своего состояния не хранят
    │   ├── Gathering.ts       # добыча хвороста из кустов и сдача в поленницу
    │   └── Fire.ts            # жар убывает, угли, связки из поленницы летят в огонь
    ├── ui/
    │   └── StoneTablet.ts     # каменная табличка: затемнение, «высеченный» заголовок, кнопки, падение с отскоком
    └── objects/
        ├── Player.ts          # вождь из нескольких картинок: ввод, шаги, взмах дубиной; таймер ударов hitTimer
        ├── CarryStack.ts      # стопка за спиной: добавить, забрать верхнюю, раскладка и покачивание
        ├── ResourceNode.ts    # куст хвороста: слой снега, запас, удар, пенёк, отрастание
        ├── DropZone.ts        # поленница: зона сдачи, куча с лимитом, забрать верхнюю связку для костра
        ├── Campfire.ts        # костёр: хранит жар, показывает его пламенем, светом и шкалой; угли
        └── Hud.ts             # интерфейс: время до рассвета, кнопка паузы, подсказка
```

Как файлы связаны:

- `main.ts` → `config.ts` → `GameScene`. `PauseScene` и `ResultScene` запускаются поверх неё.
- `GameScene` создаёт вождя, стопку, кусты, костёр, поленницу и HUD. **Объекты друг о друге не знают.** Их связывают функции из `systems/`: они получают нужные объекты аргументами и меняют их состояние. Само состояние хранят объекты (например, жар — в `Campfire`, таймер ударов — в `Player`).
- Каждый кадр `GameScene.update()` делает по порядку:
  1. `player.update()` — вождь идёт;
  2. `stack.update(спина вождя, его скорость)` — стопка едет за ним и качается;
  3. `bush.update()` — пеньки отрастают;
  4. `updateGathering()` — вождь рядом с кустом → `player.swing(x, HIT_INTERVAL, onImpact)`: замах → удар → возврат, весь взмах укладывается в `HIT_INTERVAL`. В момент попадания `onImpact` вызывает `bush.hit()` и `stack.add()` — связка летит на стопку;
  5. `updateDropping()` — вождь на поленнице → `stack.takeTop()` → `dropZone.receive()`, пока поленница не полная;
  6. `updateFire()` — жар убывает; жар ниже порога → `dropZone.takeTop()` → `campfire.receive()` → жар растёт. Жар на нуле — копится время углей; набралось `EMBER_TIME` — костёр погас;
  7. `campfire.update()` — пламя, свет и шкала показывают жар;
  8. время до рассвета убывает, `hud.setTimeLeft()`;
  9. костёр погас → поражение, время вышло → победа: `GameScene` ставит себя на паузу и запускает `ResultScene`.
- Пауза: P, Esc, кнопка в HUD или свёрнутая вкладка → `scene.pause()` у `GameScene` (замирает всё: `update`, твины, таймеры, частицы) и `PauseScene` поверх. «Заново» в паузе и в итогах → `scene.start('GameScene')`: игра создаётся с нуля.
- Числа баланса берутся из `settings.ts` (время — в миллисекундах), цвета — из `palette.ts`, картинки — только по ключам `TEXTURES` из `textures.ts`. Чтобы заменить нарисованную картинку на PNG-спрайт, меняется только `textures.ts`.
- `fx.ts` используют стопка, куст, поленница, костёр.
- Вождь собран из отдельных картинок, чтобы они двигались: ноги качаются вокруг бёдер, свободная рука — вокруг плеча, дубина — вокруг кулака. Точки вращения заданы константами вверху `Player.ts`.
