# Правила для AI-агента

Этот проект — учебная работа студента. Помогай писать код, но не забирай у студента контроль над проектом.

## Главное правило

**Делай минимальное изменение, которое решает поставленную задачу.**

Не переписывай проект целиком без прямого запроса.

## Перед изменением

1. Кратко сформулируй, что собираешься изменить.
2. Укажи файлы, которые потребуется тронуть.
3. Если задача неоднозначна, выбери самое простое решение, соответствующее текущей архитектуре.

## Во время изменения

- сохраняй TypeScript strict;
- не добавляй библиотеку, если задачу легко решить без неё;
- не создавай новые уровни абстракции "на будущее";
- не меняй несвязанные файлы;
- выноси важные игровые параметры в понятные константы;
- предпочитай маленькие функции;
- не удаляй рабочую механику без явного требования;
- не добавляй backend, базу данных или сетевую часть без явной необходимости.

## После изменения

Сообщи:

1. какие файлы изменены;
2. что именно изменилось;
3. как проверить результат вручную;
4. какие риски или ограничения остались.

Если возможно, предложи выполнить:

```bash
npm run typecheck
npm run build
```

## Запрещено

- генерировать полностью новую игру вместо изменения существующей;
- молча менять архитектуру всего проекта;
- прятать важную игровую логику в магических числах;
- добавлять платные сервисы;
- добавлять зависимость только ради нескольких строк кода.

## Контекст курса

Проект должен оставаться:

- индивидуальным;
- браузерным;
- небольшим;
- запускаемым на слабом компьютере;
- пригодным для последующей публикации и сбора игровых метрик.
